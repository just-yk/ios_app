# tools — 過去問PDF変換

`pdf_to_questions.py` は、**IPA公式の午前問題PDF**をアプリの問題形式（JavaScript）に
変換するツールです。生成結果を `data/questions-ipa.js` に反映すると、アプリに出題されます。

> ⚠️ 対象は **IPA公式が公開している試験問題のみ**（出典明記で利用可）。
> 過去問道場など第三者サイトのコンテンツには使わないでください。

## 準備（初回だけ）

```bash
pip install pymupdf
```

## 使い方

```bash
python3 tools/pdf_to_questions.py \
    --pdf   path/to/午前問題.pdf \
    --answers path/to/解答例.txt \
    --exam "基本情報技術者試験" \
    --term "令和元年度 秋期" \
    --section "午前" \
    --id-prefix fe-r01a \
    --out tools/out/fe-r01a.js
```

生成された `tools/out/fe-r01a.js` を確認し、問題なければ中身を
`data/questions-ipa.js` の `list` に貼り付けます（`source`＝出典は自動で入ります）。

### 解答ファイル（`--answers`）の書式

いずれでもOK。省略すると `answer` は `null`（後で手入力）。

| 形式 | 例 |
|---|---|
| `.txt` | 各行に `問1 ウ` / `1 ウ` / `1,ウ` |
| `.txt`（連続） | `1ウ2エ3ア…` |
| `.json` | `{"1":"ウ","2":"エ"}` |
| `.pdf` | IPAの解答例PDF（`問1 ウ` 等を自動抽出・簡易対応） |

## 出力の見方・注意

- 実行後に `検出 N問 / 解答あり N問 / 要確認 N問` を表示します。
- **`// ⚠️ 要確認`** が付く問題（図・表・プログラムを含む等）は、テキスト抽出だけでは
  不完全なことがあるため、**必ず原本PDFと照合**してください。
- `answer` が `null` の問題は、アプリ読み込み時に自動で除外されます（誤答防止）。
  解答を手入力すれば出題対象になります。
- `explanation`（解説）は空で生成されます。必要に応じて追記してください。
- `category` は既定で `technology`。基本情報の午前は3分野にまたがるため、
  必要に応じて `management` / `strategy` に手で振り分けてください。

## 仕組み・限界

- PyMuPDF でテキストを読み順に抽出し、`問N` と `ア/イ/ウ/エ` を正規表現で分解します。
- 段組みや図表を含むPDFでは取りこぼし・並び崩れが起こり得ます。あくまで
  **下書き生成**として使い、最終的な正確さは人の確認で担保してください。
