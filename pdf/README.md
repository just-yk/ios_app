# pdf — IPA公式過去問PDFの置き場

ここに **IPA公式の過去問PDF**（午前問題・解答例など）をアップロードしてください。

## 手順
1. GitHubのリポジトリ画面でこの `pdf` フォルダを開く
2. **Add file → Upload files** で、IPA公式のPDFをドラッグして Commit
3. アップロードしたら、チャットで「PDF置いたよ」と伝える
   → こちらで `tools/pdf_to_questions.py` を使って、出典つきの問題データに変換します

## 注意
- ✅ ここに置くのは **IPA公式が公開している試験問題** のみ（出典明記で利用可）
- ❌ 過去問道場など第三者サイトのPDF・解説は置かない（著作権・規約）
- ファイル名は分かりやすく（例: `fe_2019h_am_qs.pdf`＝令和元年秋 午前問題、
  `fe_2019h_am_ans.pdf`＝解答例）にしておくと変換時に指定しやすいです
